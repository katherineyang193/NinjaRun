# GitHub Pages 真人驗收

公開版本：https://katherineyang193.github.io/NinjaRun/

1. Windows 11 Chrome / Edge 打開公開 HTTPS 網址，確認首頁與五招卡。
2. 家長設定鏡頭顯示為自動，按開啟鏡頭；第一次瀏覽器應詢問 Camera 權限。先拒絕，確認有重試提示；再允許。
3. 確認模型載入、Camera ON、自己可在框內看到。退後／靠近／離開中央測試中文引導。至少頭、肩、髖、膝要清楚可見。
4. 舉起**自己實際左手**，確認進入放手步驟；放下後舉起**自己實際右手**。兩手同時抬不應通過。完成基準平均與倒數。
5. 原地左右腳小步交替跑約 2 秒，不需高抬膝，RUN ✓、runIntensity > 0。停止約 1.5 秒應 IDLE；只反覆抬同一腳或雙腿一起晃動不應 RUNNING。若仍難觸發，回報 Debug 的 Run steps、knee difference、run threshold 與 Pose FPS，毋須傳送鏡頭影像。
6. 輕跳三次，中間站穩：每跳一次應只記一次。只點頭、慢慢站直、抬一腳不應 JUMP。沒有適合跳躍空間時先關閉 Jump。
7. 蹲下保持一秒後站起；CROUCH 應只記一次。只點頭不應 CROUCH。
8. 向自己的左邊移動，应 LEFT ✓；站左邊兩秒，不能連續計数。回中央後右移，应 RIGHT ✓。
   完成後回中央，卡片須保留「✓ 已完成」與「✓ 1 次」。五招最後一招完成後，進度須保持 5 / 5；暫時離開畫面與重新校正也不能清除成果。只有開啟新一局才歸零。關閉 Jump 時目標改為 4 / 4。
9. 切換鏡像／非鏡像重試第 8 步；左右應始終是本人左右，骨架與畫面需對齊。
10. 暫時離開畫面約 3 秒，角色與練習時間暫停，顯示「回到框框裡～」。回中央後恢復，不能產生假動作或 Game Over。
11. 結束練習，確認 Camera OFF、Webcam 指示灯熄灭。練習中換分頁，回來後不能增加背景練習時間或假動作。
12. 修改 difficulty、sound、jump、mirror，保存與 Refresh，確認設定仍在；只保存設定，不保存影像。
13. 骨架節點預設顯示，確認鏡像／非鏡像時節點始終貼合影像。完整人體在框內，整框應亮黃；缺失膝蓋或離開框，整框轉藍，缺失／越界節點也標藍。手腕越界可標藍，但核心人體仍有效時不必暫停。右上可關閉節點。Debug 觀察 FPS / confidence / baseline，換相機重做校正；不要記錄影像。
14. 在一分鐘設定完整練習三局，確認休息頁；按休息完成後才能繼續。
15. 確認視訊佔滿舞台，動作提示、左右箭頭、倒數與成果全在視訊內；桌面成果浮在右側，中央膝蓋和腳部不被遮住。調整視窗確認没有橫向溢出；按「放大全螢幕」與「縮回視窗」確認可切換。相機與視窗比例不同時可留邊，不應裁掉身體。

## 開發面板怎麼看

- `phase`：目前流程。`HOME` 首頁、`LOADING` 載入、`CALIBRATION` 校正、`COUNTDOWN` 倒數、`PLAYING` 練習、`FINISHED` 完成。
- `trackingState`：`TRACKING` 看得到身體；`LOST_TRACKING` 尚未追蹤到。相機未開啟時也會是後者。
- `Pose FPS`：每秒完成幾次人體辨識；`Render FPS` 是每秒畫面更新次數。兩者分開運作。
- `Engine: OFF`：辨識模型已關閉，因此首頁 `Pose FPS: 0` 是正常的。練習中若持續為 0 且身體沒有被追蹤，才需回報排查。
- 「程式檢查（合成資料）」的五招通過是程式測試，與真人練習計數分開。查看真人成果請看招式卡與面板最後一行計數。

真人驗收需實際動作與相機；合成測試或無相機瀏覽器不能取代這些步驟。問題請附 Debug 數字、操作步驟與瀏覽器版本，毋須傳送 Camera 影像。
