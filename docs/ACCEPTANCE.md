# GitHub Pages 真人驗收

公開版本：https://katherineyang193.github.io/NinjaRun/

1. Windows 11 Chrome / Edge 打開公開 HTTPS 網址，確認首頁與五招卡。
2. 家長設定鏡頭顯示為自動，按開啟鏡頭；第一次瀏覽器應詢問 Camera 權限。先拒絕，確認有重試提示；再允許。
3. 確認模型載入、Camera ON、自己可在框內看到。退後／靠近／離開中央測試中文引導。至少頭、肩、髖、膝要清楚可見。
4. 舉起**自己實際左手**，確認進入放手步驟；放下後舉起**自己實際右手**。兩手同時抬不應通過。完成基準平均與倒數。
5. 原地左右腳交替跑至少 2 秒，RUN ✓、runIntensity > 0。停止約 1 秒應 IDLE；只反覆抬同一腳不應 RUNNING。
6. 輕跳三次，中間站穩：每跳一次應只記一次。只點頭、慢慢站直、抬一腳不應 JUMP。沒有適合跳躍空間時先關閉 Jump。
7. 蹲下保持一秒後站起；CROUCH 應只記一次。只點頭不應 CROUCH。
8. 向自己的左邊移動，应 LEFT ✓；站左邊兩秒，不能連續計数。回中央後右移，应 RIGHT ✓。
9. 切換鏡像／非鏡像重試第 8 步；左右應始終是本人左右，骨架與畫面需對齊。
10. 暫時離開畫面約 3 秒，角色與練習時間暫停，顯示「回到框框裡～」。回中央後恢復，不能產生假動作或 Game Over。
11. 結束練習，確認 Camera OFF、Webcam 指示灯熄灭。練習中換分頁，回來後不能增加背景練習時間或假動作。
12. 修改 difficulty、sound、jump、mirror，保存與 Refresh，確認設定仍在；只保存設定，不保存影像。
13. Debug 打開骨架、觀察 FPS / confidence / baseline。不同相機重做左右校正，記錄相機型號、瀏覽器、FPS、誤判與未判次数（不要記錄影像）。
14. 在一分鐘設定完整練習三局，確認休息頁；按休息完成後才能繼續。

真人驗收需實際動作與相機；合成測試或無相機瀏覽器不能取代這些步驟。問題請附 Debug 數字、操作步驟與瀏覽器版本，毋須傳送 Camera 影像。
